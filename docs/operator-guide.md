# Operator Guide

## First Deployment

1. Define the operator's household/plot coverage and household intake
   process.
2. Define consent and purpose categories for farmer/plot records.
3. Run synthetic operating cases (work-log entry, farm-operation
   scheduling, supply coordination, livelihood-concern flagging).
4. Enable human-reviewed sign-off for `:high`/`:livelihood-critical`
   actions (all flagged livelihood concerns, above-threshold supply
   orders).
5. Measure operating outcomes and audit coverage.

## Minimum Production Controls

- consent and disclosure log
- livelihood-critical escalation path (crop-failure risk, food-security
  risk, drought risk, pest-infestation risk)
- provenance for all operating records (farmer and plot both
  independently registered)
- human review for high-risk cases
- audit export for all gated actions
- a hard, unconditional block on any attempt to route a
  planting/harvest-timing agronomic decision, or an override of the
  farmer's own judgment about their household's crops, through this
  actor — those decisions stay the farmer's exclusive judgment end to
  end

## Certification

Certified operators must prove that the governor gates every
livelihood-critical robot action, that livelihood-critical risks
escalate to humans, and that no deployment configuration can route a
planting/harvest-timing agronomic decision or an override of the
farmer's own crop judgment through this actor.
